# Weather App

A responsive Weather App built with React and Vite.

## Features

- Search weather by city name.
- Display current temperature and weather conditions.
- Show humidity and wind speed.
- Display a 5-day weather forecast.
- Save the last 5 searched cities.
- Store recent searches using localStorage.
- Loading, error and empty states.
- Responsive mobile and desktop design.

## API

This project uses the free Open-Meteo API.

https://open-meteo.com/

## Technologies

- React
- JavaScript
- CSS
- Vite
- Open-Meteo API
- LocalStorage

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Install dependencies:

   npm install

4. Start the development server:

   npm run dev

5. Open the localhost link in your browser.
